# 开发交接摘要：2026-08-24

本摘要记录 `2026-08-23` 至 `2026-08-24` 合入 `master` 的主线推进和收口修复，供后续协作者恢复上下文。提交范围：`758a478` 至 `690025c`。

## 本轮目标

把五单元主线从“可跳转的页面”推进为可追溯、可验证的学习链：器件工坊发布的门电路可组合为逻辑模块，逻辑模块可解释机器与算法层的结果；同时清理不成熟的公开能力，并降低工作台回归风险。

## 已完成

### 1. 可构建计算主线

- 器件工坊已发布的门电路可以组合成半加器、全加器和八位串行进位加法器。
- 算法层的加法预测可追溯到器件工坊的已验证门；机器层运行可作为预测的交叉验证。
- 已发布模块保存完整源工作区，后续层可以安全展开回器件工坊继续检查。
- 真值表必须完整且输入组合唯一；损坏、过期或拓扑不完整的本地模块不会进入主线。

### 2. 表达与可靠性

- 算法实验以可观察的空闲态启动，不再自动执行。
- 机器桥接状态不再假称固定 WASM 可用；失败动作保留可恢复的可见说明。
- 直接拖动、旋转、阻值、坐标和触点类型编辑进入撤销历史；连续属性输入会合并，空的继电器绑定操作不会制造历史条目。

### 3. 公开边界与性能

- 未成熟的“实体搭建清单”从公开工作台标签、运行时计算和实验报告中移除；底层库与测试保留，待真实套件映射成熟后再重新开放。
- 器件面板、状态面板改为异步模块；魔方渲染/求解器保持在探索路由之后，避免进入工作台首屏负担。
- 升级 Vite 至 `6.4.3`，并锁定 `brace-expansion` 的安全版本；本地 `pnpm audit` 与生产依赖 audit 均为 0 漏洞。GitHub 的旧 Dependabot 提示可能存在扫描延迟，不能据此声称远端已清零。

### 4. 桌面工作台回归修复

- 异步侧栏未挂载时，画布曾被 CSS Grid 自动排入左列，导致画面偏移。
- 侧栏显式固定为左、中、右三列的同一行，避免异步挂载改变画布位置。
- 桌面视口会初始渲染器件面板与状态面板；小屏仍维持按需打开，避免出现两侧空栏。
