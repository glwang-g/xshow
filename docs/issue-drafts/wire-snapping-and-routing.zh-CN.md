# 优化导线吸附和走线

## 问题

导线已经可以交互编辑，但连接体验还比较粗糙。用户拖动端点时，应该能清楚知道导线将会连接到哪个端子。

## 方案

优化导线端点吸附和走线表现，让电路连接更像真实插线，也更容易阅读。

## 验收标准

- [x] 拖动导线端点时，端点会视觉吸附到附近端子
- [x] 当前可释放的目标端子有明确高亮
- [x] 如果释放在空白区域，取消重接并保留原连接
- [x] 选中的导线始终位于重叠导线和端点之上
- [x] 在可行范围内，导线走线尽量避免遮住元器件文字
- [x] 正交路径会移除连续共线点，避免端子附近出现小回勾
- [x] 同侧端子连接可以沿外侧通道绕行
- [x] 导线交叉时用视觉跨线桥表达“跨过但不连接”
- [x] 点击画布空白会同时清除元器件和导线选择

## 备注

这里应该保持轻量，不需要一开始就引入完整的图布局引擎。跨线桥只是 SVG 展示层效果，不改变电路拓扑；横向导线在交叉点留出缺口并拱起，纵向导线保持连续。
